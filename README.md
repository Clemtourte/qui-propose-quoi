# Présidentielle 2027

Site d'information sur les candidats à la présidentielle 2027, par thème et par candidat, avec sources. Accès restreint.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # validates content/ and builds dist/
```

Content lives in `content/` (YAML), schemas in `src/content.config.ts`. Editorial rules: see `CLAUDE.md`.
